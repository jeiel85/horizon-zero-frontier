## 📖 세계관 (World & Story)

> **"철과 자연이 뒤엉킨 머나먼 미래의 대지."**

알 수 없는 재앙으로 인류의 황금기가 종말을 맞이한 지 수백 년.  
지상은 야생의 원시 자연과 인공지능이 잉태한 기계 생명체들의 영역이 되었습니다.

노라 부족의 이단아 사냥꾼 **아일라(Ayla)**는 고대 유적에서 발견한 증강현실 장치 **포커스(Focus)**를 착용하고, 점차 사나워지는 기계들의 비밀을 풀기 위해 광활한 대지로 첫 발을 내딛습니다.  
부족의 성인식을 치르고, 기계들을 오버라이드하여 길들이며, 마침내 고대 지하 기계 공장 **가마솥 시그마(Cauldron SIGMA)**의 깊은 곳에 도사린 거대 기계 공룡 **선더죠(Thunderjaw)**와 맞서 싸우세요!

## ✨ 핵심 게임 특징 (Key Features)

### 1. 🗺️ 1,200m × 1,200m 광활한 심리스 오픈월드
- **노라 부족의 성스러운 계곡 (Sacred Lands)**: 완만한 언덕과 잔잔한 호수, 시작 마을 야영지.
- **붉은 협곡과 첨탑 (Sun-Carved Canyon)**: 험준한 사암 능선과 맹수 래피저의 서식지.
- **톨넥 평원 (Tallneck Steppe)**: 거대 신호탑 기계가 느긋하게 대지를 밟으며 순찰하는 남부 대평원.
- **가마솥 시그마 분화구 (Cauldron SIGMA)**: 네온 블루와 퍼플 조명이 번뜩이는 고대 지하 메카닉 벙커.
- **실시간 주야간 주기 (Dynamic Day/Night Cycle)**: 황금빛 일출, 눈부신 한낮, 붉은 노을, 별빛 가득한 밤하늘과 대기 안개.

### 2. 🏹 심도 있는 사냥꾼 전투 & 부위 파괴 (Component Tear-off)
- **사냥꾼 활 (Hunter Bow)**: 마우스 우클릭 시 슬로우 모션(집중) 어깨너머 줌. 활시위를 당겨 장력을 모아 정확하게 저격!
- **3종 특수 화살 (Ammo Types)**:
  - **충격 화살 (Impact)**: 높은 물리 관통력과 부위 파괴력.
  - **화염 화살 (Fire)**: 기계의 블레이즈 캐니스터 타격 시 연쇄 대폭발 유발!
  - **전기 화살 (Shock)**: 스턴 게이지 충전으로 기계 일시 마비 및 감전 다운.
- **창 (Spear) 근접 전투 & 기계 오버라이드 (Override)**:
  - 연속 콤보 공격.
  - 은신 또는 기절 상태의 기계에 몰래 접근하여 창으로 해킹!

### 3. 👁️ 포커스 AR 비전 (Focus Hologram Scanner)
- `V` 키를 눌러 전방위 홀로그램 AR 스캐너 가동.
- 기계의 취약 부위(약점 코어, 캐니스터, 렌즈), 체력, 순찰 경로, 그리고 숨겨진 고대 데이터포인트와 금속 꽃을 벽 너머로 투시 탐색.

### 4. 🦌 스트라이더 탑승 질주 (Mount Riding)
- 초원 지대의 스트라이더를 오버라이드하면 아군으로 길들일 수 있습니다.
- `E` 키를 눌러 등 뒤에 탑승하여 16m/s의 초고속으로 광활한 오픈월드를 질주하세요!

### 5. 🦒 거대 톨넥(Tallneck) 등반 & 맵 동기화
- 평원을 걸어 다니는 25m 높이의 거대 신호탑 기계 톨넥.
- 인근 언덕에서 뛰어내려 평평한 원반 머리 위로 착지한 후 중앙 통신 코어를 오버라이드하면 전 지역의 지도 안개가 걷히고 주요 거점이 해금됩니다.

### 6. 📜 1시간 이상 플레이 가능한 5개 챕터 메인 & 서브 퀘스트
- **Chapter 1: 사냥꾼의 증표 (The Hunter's Path)**
- **Chapter 2: 야생의 질주 (Wild Stride)**
- **Chapter 3: 도둑맞은 불꽃 (Stolen Fire)**
- **Chapter 4: 톨넥의 눈 (Eye of the Tallneck)**
- **Chapter 5: 가마솥 시그마의 심장 (Heart of Cauldron SIGMA)**
- **서브 퀘스트**: 고대 금속 꽃 5개 수집, 4대 야영지 캠프파이어 개척.

### 7. 🔥 야영지(Campfire) 세이브 & 로드 시스템
- 오픈월드 곳곳의 모닥불 야영지에서 휴식하고 체력을 100% 회복.
- `LocalStorage` 기반 다중 슬롯 (자동 저장 + 수동 저장 3개 슬롯) 완벽 지원.

### 8. 🎧 Web Audio API 절차적 사운드 & SFX 엔진
- 외부 오디오 다운로드 지연 제로!
- 활시위 당김/발사음, 타격음, 폭발음, 포커스 AR 핑 사운드, 기계 경보음, 썬더죠 포효음, 앰비언스 BGM을 브라우저에서 100% 실시간 합성 재생.

## 🤖 기계 생명체 도감 (Machine Bestiary)

| 기계명 | 등급 | 특징 및 취약 부위 | 주요 공격 패턴 |
| :--- | :---: | :--- | :--- |
| **워처 (Watcher)** | 정찰형 | 거대한 안구 렌즈 (2.5배 헤드샷 치명타) | 경보 음파, 도약 발차기, 꼬리 채찍 |
| **스트라이더 (Strider)** | 수송형 | 등 뒤 화염 캐니스터 (화염 화살 유폭) / **오버라이드 시 탑승 가능** | 뒷발차기, 뿔 들이받기 |
| **래피저 (Ravager)** | 전투형 | 등 뒤 헤비 레일 캐논 (부위 파괴 시 원거리 봉인) | 고속 도약 할퀴기, 플라즈마 캐논 연사 |
| **톨넥 (Tallneck)** | 거대형 | 평화로운 거인. 원반 머리 위 코어 (맵 동기화) | 공격하지 않음 (이동 시 지진) |
| **선더죠 (Thunderjaw)** | 보스형 | 흉부 심장 코어, 양측 엉덩이 디스크 런처 2문, 턱 기관총 | 디스크 폭격, 레이저 소총, 꼬리 대회전타 |

## 🎮 조작법 (Controls)

| 조작키 | 기능 |
| :--- | :--- |
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> | 이동 (앞 / 뒤 / 좌 / 우) |
| <kbd>Shift</kbd> (유지) | 전력 질주 (Sprint) - 스태미너 소모 |
| <kbd>Space</kbd> | 점프 (Jump) |
| <kbd>C</kbd> | 웅크리기 / 일어서기 (붉은 풀숲 은신) |
| <kbd>Alt</kbd> | 회피 구르기 (Dodge Roll) |
| **마우스 우클릭 (유지)** | **사냥 활 조준 (집중 / 슬로우 모션)** |
| **마우스 좌클릭** | **활시위 당겨 발사** (조준 중) / **창 근접 찌르기** (평상시) |
| <kbd>1</kbd>, <kbd>2</kbd>, <kbd>3</kbd> | 화살 탄종 변경 (1: 충격 / 2: 화염 / 3: 전기) |
| <kbd>R</kbd> (길게 누름) | 화살 즉석 제작 (금속 파편 소모) |
| <kbd>Q</kbd> | 노라 치유 약초 섭취 (체력 +40 회복) |
| <kbd>V</kbd> | **포커스(Focus) AR 홀로그램 비전 켜기/끄기** |
| <kbd>E</kbd> | 상호작용 / 기계 탑승 및 하차 / 캠프파이어 휴식 및 저장 |
| <kbd>F</kbd> | 자원 채집 / 상자 열기 / 오버라이드 창 찌르기 |
| <kbd>M</kbd> / <kbd>ESC</kbd> | 야영지 & 일시정지 메뉴 (세이브/로드, 퀘스트 일지, 인벤토리) |

## 🛠️ 기술 스택 (Tech Stack)

- **3D 그래픽 엔진**: [Three.js](https://threejs.org/) (WebGL2, PCFSoftShadowMap, ACESFilmicToneMapping)
- **언어 및 런타임**: [TypeScript](https://www.typescriptlang.org/), ESNext
- **빌드 도구**: [Vite 7](https://vitejs.dev/)
- **오디오 합성**: Web Audio API (Procedural Sound Synthesizer)
- **스타일링**: CSS3 (Cyber-tribal Glassmorphism, Responsive HUD, Canvas Overlays)
- **배포 & CI/CD**: GitHub Actions, GitHub Pages

## 💻 로컬 실행 가이드 (Local Development)

```bash
# 1. 저장소 클론
git clone https://github.com/jeiel85/horizon-zero-frontier.git
cd horizon-zero-frontier

# 2. 패키지 설치
npm install

# 3. 로컬 개발 서버 실행
npm run dev

# 4. 브라우저에서 http://localhost:3000 접속하여 플레이!
```
